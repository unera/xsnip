# shot — скриншот с мини-редактором

Замена `scrot` + `xclip` из вашего скрипта: снимает экран или выделенную область,
сразу открывает окно-редактор, по «готово» кладёт результат в буфер (или пишет в файл).

Один файл, Python 3 + GTK3, X11. Ни `scrot`, ни ImageMagick не нужны.

## Установка

```bash
sudo apt install python3-gi gir1.2-gtk-3.0 python3-cairo python3-gi-cairo xclip
install -m 755 shot.py ~/bin/shot      # или /usr/local/bin/shot
```

`python3-gi-cairo` обязателен: без него GTK и pycairo не видят друг друга
(`KeyError: could not find foreign type Context`).
`xclip` — чтобы картинка осталась в буфере после закрытия окна (буфер без
менеджера обмена умирает вместе с процессом).

## Использование

```
shot -s -o /tmp/a.png   # выделить область, отредактировать, сохранить в файл
shot -s                 # выделить область, отредактировать, в буфер
shot -o /tmp/a.png      # весь экран сразу в редактор, сохранить
shot                    # весь экран -> редактор -> буфер
shot -d 3               # задержка перед снимком, секунд
```

Кнопка «готово»: с `-o` пишет файл, без `-o` копирует в буфер и закрывает окно.

## Редактор

Панель: `копировать | перо  текст | толщина/кегль …  готово`.

| действие | как |
| --- | --- |
| перо / текст | кнопки или клавиши `1` / `2` |
| размер инструмента | кнопка «толщина»/«кегль» (попап со слайдером) или колесо мыши над картинкой |
| поставить текст | клик по картинке, ввод, `Enter` |
| отменить последнее | `Ctrl+Z` |
| копировать в буфер | `Ctrl+C` или кнопка |
| закрыть без сохранения | `Esc` |

Размеры — в процентах от `min(ширина, высота)` картинки, то есть одинаково
смотрятся на 800x600 и на 4K:

| инструмент | диапазон | шаг | по умолчанию |
| --- | --- | --- | --- |
| перо | 0.1 – 5 % | 0.1 | 1 % |
| текст | 1 – 50 % | 0.5 | 10 % |

Цвет — красный (`#ED2929`), полупрозрачности нет. Картинка вписывается в окно,
если она больше экрана; координаты пересчитываются, результат всегда в исходном
разрешении.

## Интеграция с i3

Вместо пайплайна `scrot` + `xclip`:

```bash
#!/bin/bash
# window | full
case "$1" in
    window) shot -s ;;
    full|"") shot ;;
esac
```

Если нужен и файл на диске, и буфер: `shot -s -o "$HOME/tmp/$(date +%s).png"`
(в редакторе при этом ещё можно нажать «копировать»).

Клавиши в `~/.config/i3/config`:

```
bindsym Print        exec --no-startup-id myshot window
bindsym $mod+Print   exec --no-startup-id myshot full
bindsym --release Print --release $mod+Print exec --no-startup-id ...
```

## Ограничения

- Только X11 (в i3 это норма). Под Wayland `Gdk.pixbuf_get_from_window` не работает.
- Мультимонитор: снимается весь виртуальный экран, а окно выделения разворачивается
  в fullscreen одного монитора — на втором мониторе выделять не получится.
- Undo — общий стек: `Ctrl+Z` убирает последний штрих или надпись целиком.
- Своих файлов не создаёт, во временный каталог не пишет: PNG живёт в памяти,
  в буфер уходит через `xclip`.

`test/` — e2e-прогоны под Xvfb (мышь через xdotool, проверка пикселей):

```bash
bash test/e2e.sh      # весь экран, штрих, сохранение по «готово»
bash test/click.sh    # точность координат: клик -> пиксель
bash test/select.sh   # выделение области 400x300
bash test/textbuf.sh  # текст + копирование в буфер
bash test/big.sh      # картинка больше окна (3000x2000)
```
