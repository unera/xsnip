# xsnip — скриншот с мини-редактором

Замена связке `scrot` + `xclip`: снимает экран или выделенную область, сразу
открывает маленький редактор (перо + текст), по «готово» кладёт результат
в буфер или в файл.

Репозиторий: <https://github.com/unera/xsnip> · пакет: `apt install xsnip`
из <https://vds2.uvw.ru/debian>.

Один файл `xsnip.c`, C99. Зависимости — только X11-библиотеки и zlib,
никаких GTK, Python и ImageMagick:

```
libX11, libXft (тянет libfontconfig, libfreetype, libXrender), zlib
```

Бинарь ~55 КБ.

## Сборка и установка

```bash
sudo apt install build-essential pkg-config libx11-dev libxft-dev libxinerama-dev \
                 libfontconfig-dev zlib1g-dev
make
sudo make install          # или: install -m 755 xsnip ~/bin/xsnip
```

## Установка из репозитория vds2

Готовый пакет собран и лежит в `https://vds2.uvw.ru/debian` (trixie и sid):

```bash
curl -fsSL https://vds2.uvw.ru/debian/repo-key.gpg \
  | sudo tee /etc/apt/keyrings/vds2-repo.asc > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/vds2-repo.asc] \
  https://vds2.uvw.ru/debian trixie main" \
  | sudo tee /etc/apt/sources.list.d/vds2.list
sudo apt update && sudo apt install xsnip
```

## Использование

```
xsnip -s -o /tmp/a.png   выделить область, отредактировать, сохранить в файл
xsnip -s                 выделить область, отредактировать, в буфер
xsnip -o /tmp/a.png      весь экран сразу в редактор, сохранить
xsnip                    весь экран -> редактор -> буфер
xsnip -d 3               задержка перед снимком, секунд
```

Буфер обмена: всё, что на холсте, уже там. Он обновляется после каждого
изменения (штрих, текст, обрезка, undo) и сразу после выделения области —
нажимать ничего не нужно. Галочка закрывает окно (с `-o` ещё и пишет файл); `Esc` и крестик делают то же
самое — поэтому скрипт, написанный под scrot, работает без правок.

## Настройки

| опция | смысл |
| --- | --- |
| `--colors c1,c2,c3,c4,c5` | палитра из пяти цветов (`#rrggbb`) |
| `--color N\|#hex` | активный цвет (N — номер в палитре, с 1) |
| `--pen PCT` | толщина пера, % от `min(w,h)` |
| `--text PCT` | кегль текста, % от `min(w,h)` |
| `--window dialog\|normal` | тип окна редактора |
| `--pos center\|tl\|tr\|bl\|br` | положение окна (от текущего экрана) |
| `-a`, `--all` | снимать весь виртуальный экран, а не один монитор |
| `--dim PCT` | яркость затемнения при выборе области: 0..100, по умолчанию **70** (раньше было 55); 100 — без затемнения |
| `-B`, `--close-on-blur` | закрывать окно, когда оно теряет фокус (по умолчанию выкл.) |

По умолчанию палитра — красный, зелёный, жёлтый, белый, чёрный; активен первый.

Всё, что выбрано в редакторе (цвет, размеры, инструмент) и задано ключами
`--window`/`--pos`, запоминается в `$XDG_CONFIG_HOME/xsnip/config`
(обычно `~/.config/xsnip/config`). Аргументы командной строки главнее
сохранённого. Чтобы вернуть заводские значения — удалить файл.

## Редактор

Панель: `↺ | перо | текст | вырезать | 5 цветов | − толщина/кегль + … ✓`.
Высота панели, шрифт подписей и иконки масштабируются от самого высокого
монитора (база — 800 точек по высоте), поэтому на 1200 и 2160 панель крупнее.
Слева — отмена (стрелка против часовой), справа две кнопки-иконки: копировать
в буфер и «готово». У перо/текст/вырезать иконка плюс подпись.

| действие | как |
| --- | --- |
| перо / текст / вырезать | кнопки или клавиши `p`/`t`/`r` (они же `1`/`2`/`3`), раскладка не важна; клавиши видны в подсказке |
| цвет | клик по квадрату или клавиши `4`…`8` |
| размер инструмента | кнопки `−`/`+`, колесо мыши над картинкой |
| поставить текст | клик по картинке, ввод, `Enter` (Esc — отменить ввод) |
| готово (как кнопка ✓) | `Enter` вне режима ввода текста |
| отменить последнее (штрих, надпись, обрезку) | `Ctrl+Z` или кнопка-стрелка слева |
| закрыть (доделав работу) | `Esc`, `Enter` или крестик окна |
| закрыть при потере фокуса | `-B`, `--close-on-blur` |

Размеры в процентах от `min(ширина, высота)` картинки, поэтому одинаково
смотрятся на 800x600 и на 4K:

| инструмент | диапазон | шаг | по умолчанию |
| --- | --- | --- | --- |
| перо | 0.1 – 5 % | 0.1 | 1 % |
| текст | 1 – 50 % | 0.5 | 10 % |

«Вырезать» — обвести прямоугольник в окне (тянуть мышью) или поставить два угла
двумя кликами: картинка обрежется до него, нарисованное сдвинется вместе с ней,
работа продолжится с уменьшенной картинкой. Обрезка попадает в стек отмены:
`Ctrl+Z` (или кнопка-стрелка) возвращает и размер, и положение штрихов.

Ввод текста идёт через XIM, поэтому кириллица работает как в остальных
X11-приложениях. Строка ввода внизу окна набирается кеглем «высота самого
высокого монитора / 25» (для 1200 — 48 px), чтобы её было видно и на
маленьком экране; на размер текста, который останется на картинке, это
не влияет. В точке вставки видна вертикальная черта высотой с кегль —
сразу понятно, где начнётся надпись. Картинка вписывается в окно (bilinear), результат — всегда в исходном
разрешении. При изменении размера окна масштаб пересчитывается один раз,
через 120 мс после остановки, поэтому рамка тянется без тормозов.

## Язык

Интерфейс переведён на английский (по умолчанию), русский и китайский.
Язык берётся из `XSNIP_LANG`, иначе `LC_ALL`, `LC_MESSAGES`, `LANG`:

```bash
XSNIP_LANG=zh xsnip -s        # китайский независимо от локали
```

Шрифт подбирается через fontconfig под язык (для китайского — шрифт с CJK),
а внутри строки — посимвольно: латиница и кириллица берутся из обычного
шрифта, иероглифы — из CJK-шрифта.

## Тайловые WM (i3)

- `--window dialog` (по умолчанию): окно помечено `_NET_WM_WINDOW_TYPE_DIALOG`,
  i3 держит его floating, `--pos` применяется — проверено на i3 4.24
  (`floating=auto_on`, окно село в заданный угол).
- `--window normal`: обычное окно, i3 его тайлит, `--pos` игнорируется.

Окно выделения области — `override-redirect`, WM его не трогает вообще:
оно всегда во весь экран поверх всего. Рамка рисуется XOR-операцией, а
осветлённая область показывается, когда мышь останавливается (120 мс), —
выделение на двух мониторах не тормозит.

## Буфер обмена

После закрытия редактора картинку в буфере держит форкнутый процесс-демон
(своя реализация X11 selection: `image/png`, при большом размере — по
протоколу INCR). Поэтому данные не пропадают, когда `xsnip` завершился.
Демон выходит сам, когда владение выбором забирает другая программа.
`xclip` не нужен.

## Ограничения

- Только X11. Под Wayland (sway) `XGetImage` корневого окна не работает.
- Мультимонитор: мониторы определяются через Xinerama; без `-s` берётся экран
  под указателем, `-a` снимает всё. Окно выделения растянуто на весь
  виртуальный экран, чтобы можно было выделять через границу мониторов.
- Undo общий: `Ctrl+Z` убирает последний штрих, надпись или обрезку целиком.
- Слайдера размера нет: `−`/`+` и колесо.

## Файлы

- `xsnip.c` — вся программа
- `Makefile` — сборка через pkg-config
- `debian/` — упаковка (non-native, 3.0 quilt)
- `man/xsnip.1` — man-страница (английский), `man/ru/` и `man/zh_CN/` — переводы;
  устанавливаются в `/usr/share/man/{,ru,zh_CN}/man1`
- `legacy/shot.py` — первая версия на Python+GTK3 (оставлена для истории)
- `test/` — e2e-прогоны под Xvfb + xdotool, включая проверку на настоящем i3:

```bash
bash test/c_e2e.sh      # штрих + сохранение по «готово»
bash test/c_select.sh   # выделение области 400x300
bash test/c_text.sh     # ввод текста (XIM) + файл
bash test/c_clip.sh     # буфер обмена
bash test/c_color.sh    # выбор цвета + запись настроек
bash test/c_args.sh     # --colors/--color/--pen/--text/--window/--pos
bash test/c_persist.sh  # настройки переживают перезапуск
bash test/c_incr.sh     # PNG больше 256 КБ через INCR (3000x2000)
bash test/c_i3.sh       # ничего не падает; dialog/normal под i3 4.24
bash test/c_asan_run.sh # прогон под ASan
```
